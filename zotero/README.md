# zotero

Go building blocks for the Zotero Web API v3 data model, extracted from the
[gotero](https://github.com/robertjndw/gotero) sync server. Apache-2.0.

```
go get github.com/robertjndw/gotero/zotero
```

| Package | What it has |
|---|---|
| `zotero` | object keys, `OrderedMap`, `Merge` (POST patch semantics), write/deleted/fulltext/key/group response types, `MarshalItemData` |
| `zotero/schema` | item types, ordered fields, creator types and the schema version each field appeared in, generated from the official schema |
| `zotero/stream` | WebSocket protocol messages, topics and close codes (no WebSocket dependency) |

## Examples

Merge a client's patch into a stored item and render it in the field order
the desktop client expects:

```go
var stored, patch zotero.OrderedMap
_ = json.Unmarshal(storedJSON, &stored)
_ = json.Unmarshal(patchJSON, &patch)

merged, changed := zotero.Merge(stored, patch)
if !changed {
	// report as "unchanged", keep the old version
}
merged.Set("version", json.RawMessage("42"))

// Leave out fields a client with schema version 33 doesn't know.
out, err := zotero.MarshalItemData(merged, schema.Default(), 33)
```

Parse query parameters:

```go
keys, err := zotero.ParseKeyList(r.URL.Query().Get("itemKey"))
tags := zotero.ParseTagList(r.URL.Query().Get("tag")) // "a || b"
since, present, err := zotero.ParseVersionHeader(r.Header.Get("If-Modified-Since-Version"))
```

Handle a stream frame:

```go
msg, err := stream.ParseClientMessage(frame)
if err != nil {
	// close with stream.CloseBadRequest
}
subs, _ := msg.Normalize()
reply, _ := json.Marshal(stream.SubscriptionsCreated{Subscriptions: subs})
```

## Schema data

`schema.Default()` is generated by `cmd/schemagen` from
[zotero/zotero-schema](https://github.com/zotero/zotero-schema) at a pinned
commit (recorded in the header of `schema/schema_gen.go`). Only factual
tables are included: item type and field names, their order, base-field
mappings, creator types and the schema version in which each field first
appeared. To regenerate, run `go generate ./schema`. To use a newer schema at
runtime, pass an official `schema.json` to `schema.Load`; fields loaded that
way report introduction version 0 and are never filtered.

## Stability

This module is v0. Exported names and signatures may change in any release
until v1.
